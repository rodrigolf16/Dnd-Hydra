GUÍA DEL DM

Cómo dirigir la mesa con dados físicos

1. Carga las iniciativas físicas

Pulsa ✎ Cargar iniciativas, escribe lo que sacó cada jugador y enemigo en la mesa y ordénalos de mayor a menor. Usa ⇄ Intercambiar si alguien activa la dote Alerta.

2. Registra cada movimiento y anota los dados físicos

Al abrir un ataque, conjuro o acción, Ronda indica exactamente cuántos dados físicos tirar (ej. 2d6+1d4+5 · 3 dados). Anota el d20 físico para comprobar si impacta la CA y luego anota el daño físico para descontarlo automáticamente de la barra de vida.

3. Panel de Dados Físicos libre (derecha)

Para salvaciones, trampas o pruebas sueltas, toca d20..d4 para sumar cantidades, anota el total obtenido en la mesa y regístralo o aplícalo directo como daño o curación.
